# Пик Олимпиады

Подготовка к математическим олимпиадам **FEMO, AMO и SASMO** для учеников 3 класса: игра и две интерактивные рабочие тетради. Работает в браузере, установка не нужна.

## Что внутри

| Папка | Что это |
|---|---|
| `game/` | **Барс и Пик Олимпиады** — игра для телефона: 12 миров, 324 задачи, битвы с монстрами, звёзды, монеты, награды, лавка вещей для героя, блиц на 60 секунд с генератором задач |
| `workbook-1/` | Тетрадь 1: 9 тем, уроки с алгоритмами, 144 задачи, 2 пробные олимпиады |
| `workbook-2/` | Тетрадь 2 (для телефона): 10 тем, 120 задач посложнее, задание дня, 2 пробные олимпиады |
| `index.html` | Стартовая страница со ссылками на всё |

Каждая страница — один самостоятельный HTML-файл. Шрифты подгружаются из Google Fonts; без интернета будут системные шрифты.

## Как запустить у себя

Скачайте архив, распакуйте и откройте `index.html` в браузере.

## Как опубликовать на GitHub Pages

1. Создайте новый репозиторий на GitHub (например, `pik-olimpiady`).
2. Загрузите в него **содержимое** этой папки (файлы `index.html`, `README.md`, `.nojekyll` и папки `game`, `workbook-1`, `workbook-2`) — через кнопку **Add file → Upload files** или через `git push`.
3. Откройте **Settings → Pages**, в разделе **Build and deployment** выберите **Deploy from a branch**, ветку `main` и папку `/ (root)`, нажмите **Save**.
4. Через 1–2 минуты сайт будет доступен по адресу `https://<ваш-логин>.github.io/pik-olimpiady/`.

Чтобы дать архив для скачивания: **Releases → Draft a new release**, прикрепите zip-файл и опубликуйте.

## Прогресс

Звёзды, монеты, награды и решённые задачи хранятся в `localStorage` браузера — на каждом устройстве свой прогресс. Лучше играть на одном и том же телефоне.

## Об авторских правах на задачи

Все задачи авторские, составлены по темам и форматам олимпиад для 3 класса. Официальные прошлые варианты можно найти у организаторов: [femo.kz](https://femo.kz), [amo.sg](https://amo.sg/).
